// 02 — features

True TDMA engine

8 slots per 4.615 ms frame, BCCH slot 0 always on, 26-multiframe idle rhythm, 28 us PA ramps — the buzz, not a beep.

7 bands, 7 voices

450 / 480 / 850 / 900 / R / 1800 / 1900 with real UL/DL ranges, per-band hash EQ, mains hum and PSU whine.

Tower-close mode

Proximity presets, SDR drive with soft clipping, solid-BCCH dummy bursts: from −109 dBm hairline to full-scale carrier.

IQ export

1.083 MS/s GMSK with FCCH/SCH/BCCH structure for SDR++ file source (.cu8 + IQ WAV).

Width / TRX / Scene

BT + ramp control, up to 4 carriers on the 200 kHz raster, Clean tower or Dense urban 900 scenes.

C++ disguise

Ships as .cpp — compiles as C++ into a stub, runs as Python. The exe needs no Python at all.

// 05 — build from source

pip install pyinstaller numpy scipy matplotlib sounddevice
copy openGSMTower.cpp openGSMTower_app.py
python -m PyInstaller --noconfirm --clean --onefile --windowed --name openGSMTower ^
  --icon openGSMTower.ico --add-data "openGSMTower.ico;." ^
  --hidden-import sounddevice --hidden-import scipy.signal ^
  --hidden-import scipy.special --collect-all sounddevice openGSMTower_app.py

Or run from source directly: python openGSMTower.cpp (flags: --test-synth, --export-iq [secs] [name]).
