OFDM-ish hiss chopped by the DDDSU pattern plus a 50 Hz SSB throb. Flip FDD for pure continuous hiss, or raise SCS and hear the switching buzz climb 200 → 400 → 800 Hz. (Keep volume low.)

// 02 — features

Real numerology

15/30/60 kHz SCS with correct slot timing — the TDD buzz pitch follows the standard.

6 NR bands

n28 / n1 / n3 / n7 FDD plus n40 / n78 TDD, duplex auto-detected per band.

SSB ticks

Burst sets every 10/20/40 ms with a dedicated 20 ms scope view and DDDSU slot LEDs.

NR IQ export

7.68 MHz captures: band-limited carrier, bright SSB ticks, TDD gating (.cu8 + IQ WAV).

Tower-close mode

Proximity presets + soft-clipped SDR drive, output picked before Start.

C++ disguise

Ships as .cpp — compiles as C++ into a stub, runs as Python. Exe needs nothing.

SCS 15/30/60 kHz SSB every 10/20/40 ms TDD DDDSU IQ 7680000 Hz

// 04 — build from source

pip install pyinstaller numpy scipy matplotlib sounddevice
copy open5GTower.cpp open5GTower_app.py
python -m PyInstaller --noconfirm --clean --onefile --windowed --name open5GTower ^
  --icon open5GTower.ico --add-data "open5GTower.ico;." ^
  --hidden-import sounddevice --hidden-import scipy.signal ^
  --hidden-import scipy.special --collect-all sounddevice open5GTower_app.py

Or run from source directly: python open5GTower.cpp (flags: --test-synth, --export-nr [secs] [name]).
